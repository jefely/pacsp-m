## 8. 一项否定结果：素参不在嵌入空间内

### 8.1 对象

框架（PACSP-ID 及素材）把**素参**定义为「勒贝格分解的奇异分量」`dM`
（`dΛ = ρ dν + dM`），并称其为：

> 不是「我们测量不到的东西」，而是「我们在测量中必然留下的残余」。
> 它不是**认识论**的缺陷，而是**本体论**的结构。

**1.1.0 没有检验它。** 本节报告四次操作化尝试——**四次都以同一方式失败**，
而第四次失败**给出了原因**。

### 8.2 四次尝试，同一个结构

| # | 做法 | 引入的自由参数 | 结果由谁决定 |
|---|---|---|---|
| 1 | 用勒贝格分解求奇异部分 | 参考测度 `ν` | `ν` 处处为正 → `dM = 0` 是**构造必然**：检验**不可能失败** |
| 2 | 固定 `ν`，扫覆盖半径 `r` | 半径 `r` | 六臂临界倍数**都是 1.50×**——几乎是最近邻距离分布形状的**定义性陈述** |
| 3 | 三族互不相关的构造，扫阈值 `ε` | 阈值 `ε` | 探针查明：全部六个个体到外来基底的**中位最近距离在 0.665–0.928**，而 `ε = 0.3/0.5` **低于全部六个** → 基底**一点没吸收到** |
| 4 | 同上，但严格满足「基底丰沛、真正外部、尺度自定」 | —— | 见 §8.3，**第四次不是失败，是证明** |

> **共同结构：每一次「把素参操作化」，最终决定结果的都是实验者引入的那个自由参数，
> 而不是数据。**

**第 3 次的探针尤其干净**：残余量恒为 1.0000，三个构造族当然一致——
**那个「三族同底 18/18」什么也没证明，已撤回。**

### 8.3 决定性的一步：尺度无关的「残余」可证明为空

不再纠缠于选哪个 `ε`，而是**把 `ε` 全扫一遍**，看残余作为 `ε` 的函数的整体行为：

```
residue(ε) = Λ 中距基底 > ε 的那部分质量占比
```

实测（`exploration/g1_F_test.py`，10 个臂）：

| 臂 | ε=0.6 | ε=0.8 | ε=1.0 | ε=1.5 | ε=2.0 |
|---|---|---|---|---|---|
| hc3_ai_medicine | 0.8407 | 0.4306 | 0.0693 | 0.0000 | **0.0000** |
| techdoc | 0.4181 | 0.1168 | 0.0000 | 0.0000 | **0.0000** |
| lyrics | 1.0000 | 1.0000 | 0.0000 | 0.0000 | **0.0000** |
| poem | 0.9101 | 0.0704 | 0.0000 | 0.0000 | **0.0000** |
| …（10 臂全部） | | | | | **0.0000** |

**单调不增：✅ 全部成立。**
**`ε = 2.0`（单位球的直径）时全部为 0——这不是测量结果，是上界。**

于是：

```
⋂_{ε>0} (未被 ε 吸收的部分)  =  ∅
```

> **尺度无关的「残余」不存在。这是可证明的，不需要实验。**

**对任何固定的 `ε`，残余都是 `ε` 的函数；对所有 `ε` 取交集，得到空集。**

### 8.4 命题 F 是空洞的

```
F =「存在有限的外部基底序列把残余驱到 0」

  若 ε 可取大  →  F 平凡成立，什么也没说
  若 ε 固定    →  F 的真假完全由 ε 决定，不是关于世界的事实
```

**`F` 不能区分任何东西。** 它既不是真的也不是假的，是**没有内容**。

**这解释了前三次失败的共同根因**：它们不是在**测**一个难测的东西，
而是在**测一个不存在的东西**。**所以不可能被第五次设计修好。**

### 8.5 反证：素参必然在嵌入空间之外

否定性结果反过来给出一条**正面论证**：

```
1. 「空间内的残余」必然依赖一个尺度选择                     （§8.3）
2. 尺度无关的交集为空                                       （§8.3，已证明）
3. ∴ 素参 ≠ 嵌入空间内的任何残余
4. ∴ 素参不在嵌入空间内
5. 「不在系统内」正是「系统外固定」的意思
6. ∴ 素参若存在，则该系统不封闭
```

**这条链的第 5 步是定义，不是推论**：一个系统的内部量若其值不由内部决定，
就只能由外部固定。**这是「封闭」一词的直接含义。**

> **所以素参找不到，不是因为仪器不够好，而是因为它不在空间里——
> 而这一点现在有证明了。**

这与框架自陈的「零层 / 本体论核心 / 不是认识论缺陷而是本体论结构」**完全一致**：
**一个"条件"不能作为对象出现在它所条件化的系统里。这就是它不可定义的原因——
不是难，是类型上不允许。**

### 8.6 前提（必须明写）

第 3 步用到一个前提：**嵌入空间里没有「特权尺度」**。

**这是合理的**（1024 维连续空间没有内禀尺度），但**必须说出来**。
若有人声称存在特权尺度，那么：

- 他**必须指名是哪个**；
- 素参随即成为**关于那个尺度的相对量**；
- 而**框架从未指名任何尺度**。

**所以两种情况下框架都欠一步**：要么承认素参不在空间内，要么给出特权尺度的名字。

### 8.7 因此什么才是可证伪的

**可证伪的是它的弱化形式 `F`，而且 `F` 是单边决定性的**：

| 结果 | 能断定什么 |
|---|---|
| **找到**这样的序列 | ✅ **决定性**：素参不存在，且系统封闭 |
| **找不到** | ⚠️ **什么也断定不了**——可能是序列不够丰沛 |

**方向是对的**：找到就**证伪素参**，找不到只是**未能证伪**。

**已做四次尝试，均未找到。** 但 §8.2 说明前三次的失败**源于设计缺陷**
（自由参数接管结果），**不是「丰沛基底仍留下残余」**。

> **所以关于 `F`，目前的状态是：未找到，而这不是「证明了不存在」。**

### 8.8 不主张的

1. **不主张「素参不存在」。** 本节证明的是**它不在嵌入空间内**，不是它不存在。
2. **不主张「世界是虚拟的」。** §8.5 的第 6 步（系统不封闭）是形式推论；
   从「不封闭」到「虚拟」还需要一个定义前提（「受外部作用」=「被模拟」），
   **那个等号不是形式推论**，本框架不主张它。
3. **不主张 `F` 已被检验。** 四次都不是合格的 `F` 检验（§8.2）。
