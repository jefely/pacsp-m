# 认知沉积的表示与效度：产物、过程与结构

**版本**：PACSP-M 1.2.0
**名称**：**PACSP-M** = *Pairwise Average Cognitive Semantic Proximity — Measurement*
（成对平均认知语义接近度的测量框架）
**性质**：一个完整、正面描述的测量框架。不是修订清单。
**演变来源**：PACSP-M 1.1.0（见附录 C）
**方法定位**：本文先给出**可靠的部分**，再给出**被实测否决的部分**及否决依据；
并逐条标注哪些结论沿自 1.1.0、哪些已被取代。

〔关于名称〕`M` 指 **Measurement**，即"测量框架"。它**不是** "Modified"。
名称中的 `D`（度量）取自 *pairwise average* 的首字母与 *proximity* 的语义。
