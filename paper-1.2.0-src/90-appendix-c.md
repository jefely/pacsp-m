## 附录 C：与 1.1.0 的关系及本次方向变更

| | 1.1.0 | **1.2.0（本文）** |
|---|---|---|
| 问题 | 语料作为**无序集合**，其分布形态能否区分两组文本 | 同上，**加上**过程侧的表示与结构 |
| 表示 | **只**用集合（判为框架级结论） | **按问题选**：集合 / 序列 / 序列+骨架 |
| 与过程侧的关系 | 明确放弃（§3、§8.1） | **接回**（§5、§6） |

**本文不是 1.1.0 的补丁，而是把 1.1.0 的一个越界断言退回其范围，
并把该断言导致放弃的那一半工作接回来。**

### C.2 触发变更的那一步

1.1.0 §3.4 的推理链是：

```
C_T 顺序敏感（20–51%）
  → 局部化修不好（narrow 0.2457 > window 0.1915）
  → 顺序敏感是「沿序列求和」的内禀性质
  → ∴ 放弃序列表示
```

**前三步在 1.1.0 的数据内成立。第四步不成立，有两个独立理由：**

**理由一（概念）**：1.1.0 测的是**任意文件顺序**，那个顺序**没有物理意义**。
用它否定在**生成顺序**（有物理意义）上才成立的表示，是**用错了对象**（§3.3.0）。

**理由二（实测）**：
- **方向保持率 100%**——两臂各自独立重排 200 次，
  全部 `μ` 变体的人机方向都保持（§3.3.1）。**顺序不改变结论的方向。**
- **`rn_selfnorm` 0.0967** 优于 `μ ≡ 1` 的 0.1399 达 31%，**且仍是序列量**（§7.4）。
  **所以「要消除顺序敏感必须放弃求和」是错的。**

### C.3 本次相对 1.1.0 的六处关键修正

| # | 1.1.0 | 1.2.0 | 依据 |
|---|---|---|---|
| 1 | 语料**是**集合，不是序列（§3 标题、结论第 2 条） | 表示**按问题选**；顺序分两种，性质相反 | §3.3.0 |
| 2 | 顺序敏感是内禀缺陷，故放弃求和 | 顺序敏感是**要报告的量**；方向保持率 100% | §3.3.1 |
| 3 | `μ ≡ 1`（0.1402）是全部变体中最好的 | **已被取代**：`rn_selfnorm` 0.0967，且仍是序列量 | §7.4 |
| 4 | `D` 是"核心度量" | `D` 是**产物侧**的度量；过程侧另有 `S` 与情绪树动态区域 | §3.2、§5、§6 |
| 5 | 过程侧未测 | 过程侧两个测度跨编码器成立，含 `D` 失效的家族 | §5.3、§6.4.4 |
| 6 | 素参未检验 | 素参**不在嵌入空间内**（已证明）；命题 `F` 空洞 | §8 |

**第 1、3、6 条是本文相对 1.1.0 最实质的三处。**

### C.4 未变的部分（1.1.0 的真资产）

以下内容**逐字或近乎逐字保留**，因为经本文复核仍然成立：

1. **§1 构造原则**：P1 / P1′ / P2，及其推导（三种替代表示都以同一方式失败）。
2. **§2 参照系** `(Ω,d,M)`，及"`M` 必须显式声明"的实测依据（换模型差 31%）。
3. **§9（原 §5）被实测否决的部分**：`C_T` 作为沉积总量、核嵌入、匹配矩阵图、残差修正，
   及各自的复活条件。**本文对 `C_T` 的处理不与之矛盾**：
   被否决的是它**作为"沉积总量"**，不是它作为一个**序列统计量**（§7 给了它忠实的定义）。
4. **§10（原 §6）报告规范**：五条必需检验、报告模板、两条操作判据。
   **本文增加了第 5 条**（顺序敏感度须与方向保持率一同报告）。
5. **§11（原 §7）明确不主张的**四条，本文另加 §8.8 的三条。
6. **附录 A 可复现性、附录 B 数值来源、参考文献。**

### C.5 一个诚实的总结

**1.1.0 不是错的，它是"一个正确回答了一个项目已经走过的问题"的论文。**

它把产物侧做到了很干净的程度，并且**自己写出了那条边界**（§8.1：
"分布形态是产物，生成动力学是过程……`D` 原则上不能回答认知沉积是什么"）。
**它唯一越界的地方，是把'产物侧用集合'写成了'语料是集合'，并据此放弃了另一侧。**

**本文做的是三件事**：
1. 把那一步退回范围（§3）；
2. 把被放弃的那一半接回来，并给出它的实测（§5、§6）；
3. 把两处遗留的技术问题解决掉——`μ` 的忠实定义（§7）与素参的定位（§8）。

**以及一处必须重申的**：本文的全部结果**仍然是关于嵌入空间中的形态与结构的**，
**不是关于认知沉积本身的**。这一条 1.1.0 说对了，本文不改。
