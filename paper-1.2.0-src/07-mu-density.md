## 7. `μ` 的忠实离散化，以及顺序敏感度的正确读法

§3 判定「顺序敏感是要报告的性质，不是要消除的缺陷」，但**没有回答一个独立的问题**：
**`C_T = Σ_k μ_k δ_k` 里的 `μ_k` 定义对不对？**

1.1.0 §3.4 把它当作"顺序敏感的一个变体"来测。**本节说明它其实是一个类型错误**，
并给出一个**可核对的忠实地定义**。

### 7.1 现行实现的类型错误

`PACSP-ID` 与 1.1.0 的 `window` 实现：

```
μ_k = 1 − （第 k 个点周围半径 5 的窗口内，所有点对的平均余弦相似度）
```

**这个量衡量的是「一片邻域内所有点彼此像不像」，
却拿去乘「单独第 k 步的位移 `δ_k`」。**

> **加权某一个格子的量，必须是那个格子自己的性质。**
> 邻域平均不是单格的性质——这是**类型错误，不是精度不足**。

**这解释了一个 1.1.0 无法解释的反常**：直觉上「越局部越忠实」，
实测**半径缩小反而更糟**（`narrow` 0.2461 > `window` 0.1918）。

**因为缩小窗口不是消除错配，而是把错配磨得更尖**：
半径 5 时 `μ_k` 是个迟钝的平均，抖动被抹平了一些；半径 1 时它变得极敏感。

**所以「把 `μ` 改得更局部」这条路走不通**——错在类型，不在尺度。

### 7.2 忠实的定义：Radon–Nikodym 密度

密度的定义就是**同一格上的两个测度之比**：

```
ρ_k = Λ(格 k) / ν(格 k)
```

- `Λ` = 路径自己的测度（第 k 格上的质量就是 `δ_k`）
- `ν` = 参考测度（框架文本里称「**公共认知基底**」）

**`ρ_k` 只用到第 k 格自己的两个数**，所以它**在构造上就是逐单元的**——
不是"把一片区域的平均值硬当局部权重"。

**框架自己早就写了这个式子**：素材中的 `dΛ = ρ dν + dM` 就是它。**`μ` 本来就该是 `ρ`。**

### 7.3 验证锚点：一个恒等式，不是容差

密度必须能积分回去：

```
Σ_k ρ_k · ν_k  =  Σ_k δ_k  =  Λ 的总量
```

实测（`exploration/g1_rn_density.py`，6 语料 × 4 变体 = **24/24 通过**）：

> **最大绝对误差 0.000e+00。**

**任何不满足这条恒等式的候选，连"密度"都不算，直接被拒，`C_T` 都不用算。**
这是 `μ` 这个问题上**第一个精确锚点**。

### 7.4 结果：忠实版本确实更稳，但代价是真的

九个变体的完整对照见 **§3.3.2 的表**。要点：

| | 顺序敏感度 | 人机比值 | 重排下方向保持 |
|---|---|---|---|
| `window`（1.1.0 现行） | 0.1918 | **1.296** | 100% |
| `none`（`μ ≡ 1`，1.1.0 最优） | 0.1399 | 1.085 | 100% |
| **`rn_selfnorm`**（忠实） | **0.0967** | 1.085 | 100% |

**`rn_selfnorm` 取 `ν = Λ` 的总量（常数），于是 `ρ_k = δ_k / Σδ` 是一个概率分布**：

```
Σ_k ρ_k = 1        C_T = Σ_k ρ_k δ_k = E_ρ[δ]
```

**用人话说**：`C_T` 成为「**当路径走得大的时候，典型的一步有多大**」——
路径自己质量加权的平均步长。干净、可解释、**天生自归一**。

**代价必须写明**：更稳的变体把效应量压小了（1.085 对 1.296），
而 §3.3.1 的决定性检验说明**两者的对比都是真的**（100% 重排保持）。
**这是判别力与可复现性之间的真实取舍，不是精度差别。**

**本框架的选择：保留 `window`，判别力优先。**

### 7.5 `μ ≡ 1` 的精确含义（一个漂亮的重述）

1.1.0 把 `μ ≡ 1` 读作「把权重去掉」，听起来像放弃。**用密度语言看，它有精确含义**：

```
若 ν = Λ（参考测度就是路径测度本身）
则 ρ = dΛ/dΛ = 1   恒等于 1
```

> **`μ ≡ 1` 不是「去掉权重」，而是「选择 `ν = Λ`」**——一个完全合法的选择。

**这个重述把问题改写了**：

| | 旧问法（1.1.0） | 新问法（本节） |
|---|---|---|
| 问题 | 保留 `μ` 还是去掉 `μ`？ | **`ν` 取哪个参考测度？** |
| 含义 | 像"要不要放弃理论" | `ν = Λ` 只是选择空间里的**一个点** |

**既然它是一个点，就有别的点可以试**——`rn_selfnorm` 就是其中更好的一个。

### 7.6 这一节对 1.1.0 的核心结论做了什么

| 1.1.0 的结论 | 本节的结果 |
|---|---|
| `Σ μ_k δ_k` 不是 `∫ μ dΛ` 的忠实离散化 | ✅ **成立**，且给出了**为什么**（类型错误）与**怎么修**（RN 密度） |
| 局部化不能修复它 | ✅ **成立**，且解释了为什么（缩小窗口磨尖错配） |
| `μ ≡ 1` 是全部变体中最好的 | ❌ **已被取代**——`rn_selfnorm` 0.0967 优于它 31% |
| 要消除顺序敏感必须放弃求和 | ❌ **不成立**——`rn_selfnorm` 仍是序列量，且更稳 |
| 因此语料应表示为集合 | ❌ **不成立**——见 §3 |

**前两条是 1.1.0 的真发现，本节保留并补足了机制。后三条已被取代。**
