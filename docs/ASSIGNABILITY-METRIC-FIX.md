# 修正：可归类性判据用错了指标

**日期**：2026-10-05
**触发**：用户问「为什么 D 比值 0.8305 那么远，却说不能分类」
**脚本**：`tools/check_assignability.py`
**结果**：`records_centroid/assignability_check.json`

---

## 一、问题

工具的 `not-assignable` 闸门以**重叠占比 > 0.5** 为判据，对 `poem`/`machine_poem` 输出：

> 「the collections interpenetrate, so single items cannot be classified」

**用户直接问：比值那么远，为什么不能分类？** 我没有只解释设计意图，而是**实测了可分性**——

```
留一最近质心分类正确率        0.984      （62 篇中 1 篇落在错侧）
工具据以判定的重叠占比        0.797
```

**两者矛盾，而工具错了。**

## 二、实测：闸门 5 对中错 4 对

| 配对 | 重叠占比 | **留一正确率** | 留一逻辑回归 | 工具判定 | |
|---|---|---|---|---|---|
| poem | 0.7971 | **0.9839** | 1.0000 | not-assignable | ❌ **错** |
| lyrics | 0.0656 | 1.0000 | 1.0000 | some assignability | ✅ 蒙对 |
| techdoc | 0.9261 | **0.6935** | 0.9677 | not-assignable | ❌ **错** |
| medicine | 0.8106 | **0.9194** | 0.9194 | not-assignable | ❌ **错** |
| openqa | 0.8543 | **0.9194** | 0.9194 | not-assignable | ❌ **错** |

```
Spearman(重叠占比, 留一正确率) = −0.90
```

**关键在最后一行。**

> **`重叠占比`与真实可分性强烈负相关。**
> **我用一个近乎反向的指标当作可分性的代理。**

〔`lyrics` 是唯一蒙对的，但**方向是反的**〕它重叠低（0.066）、可分性高（1.000），
看似"低重叠 ⟹ 可分"，实际是"低重叠 ⟹ 域内更同质 ⟹ 可分性反而更高"——
**两次否定恰好等于肯定**，纯属巧合。

## 三、为什么会错

| | 重叠占比 | 可归类性 |
|---|---|---|
| 问的是 | **交叉距离分布**落在组内半径内的比例 | **每一篇**相对两个质心的位置 |
| 维度 | 1 维摘要（961 个距离压成一个数） | 每篇独立的几何判定 |
| 论文已量出 | §4.11：`r = −0.0143` 与 `D` 比值几乎不相关 | — |

**我在论文 §4.11 里已经量出这两个量不相关，却仍然把前者当成后者的代理。**

〔一层更深的错〕这不是"阈值选得不好"（0.5 换 0.8 也没用），
**是选错了量**。重叠占比描述的是"两个距离云共享多少"，那是真实的、有用的信息，
**但它不描述可分性**。

## 四、修正

### 判据改为留一最近质心正确率

```
每篇文本用「不含它自己」的两个质心判定归属
正确率 0.5 = 乱猜，1.0 = 完美可分
```

**修正后**：

```
poem  accuracy 0.984  →  NOT not-assignable  →  VERDICT: separable
      「62 篇中 1 篇落在错侧」
```

### 两个量都报告，但只用正确的那个做判定

```
overlap        0.7971    ← 仍然报告，描述距离云共享程度
assignability  0.9839    ← 判据；留一最近质心，chance 0.5
```

### 未测时不猜

若调用方没传 `assign`，闸门输出：

```
[assignability] overlap share 0.797 is reported, but assignability was not
                measured; do not read the overlap as if it were
```

**而不是沉默地退回旧判据。**

## 五、验证

`tests/test_tool_matches_paper.py` 现在**双向**测：

| 用例 | 正确率 | 期望 | 实测 |
|---|---|---|---|
| openqa（真实可分） | 0.9194 | 闸门**不**触发 | ✅ |
| 合成重叠云 | 0.525 | 闸门**触发** | ✅ |
| 未传 accuracy | — | 闸门声明"not measured" | ✅ |

**两个方向都测是必要的**——只测"不该触发"会漏掉一个永远不触发的坏闸门。

## 六、对论文的影响

论文有三处结论需要改：

| 位置 | 原文 | 应改为 |
|---|---|---|
| **§4.11** | 「5 对中只有 `lyrics` 支持单篇可归属」 | **5 对中 4 对支持**（正确率 0.69–1.00，仅 `techdoc` 较低） |
| **§4.11 操作判据** | 「不要用 `D` 的比值推断单篇可分性」 | 仍然成立，但**理由换了**：不是"不可分"，而是"比值不衡量可分性" |
| **§8 结论 8.1** | 「只在极少数情况下才回答单篇能否归属」 | **在多数情况下可以回答**，但要用正确的方法（留一分类），不是重叠占比 |
| **§7.1** | 「`D` 的差异不是来自机器文本更整齐」 | 不变 |

**方向变了，而且变得更重要**：原先的意思是"测量能力有限"，
现在的意思是"**测量能力比先前报告的更强，但先前用错了指标**"。

## 七、限制

| # | 限制 |
|---|---|
| 1 | **留一最近质心假设簇近似球形**。`techdoc` 的 0.6935 与逻辑回归的 0.9677 差距大，说明该域形状偏离球形；**两个数都报告更稳妥** |
| 2 | **只有 5 对**，Spearman `−0.90` 是强证据但不构成定律 |
| 3 | **未在其他参照系上复核**。§4.9 已显示换家族会改变判别力，正确率也可能随之变化 |
| 4 | **未做样本量敏感性**——每侧 31 篇，正确率的区间未估计 |

〔限制 4 值得做〕正确率 0.984 与 1.000 的差距在 n=62 时是否有意义，需要区间。
