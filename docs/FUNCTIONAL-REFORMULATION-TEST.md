# 泛函重构的检验：Se(γ) = Φ(γ)

**日期**：2026-10-05
**被检验的提案**：标量 `C_T` → 核嵌入函数 `Φ(γ)(x,t) = K(x, γ(t))`，
主张单射性、`argmax` 自动还原、以及"顺序从噪声变为信号"。
**方法**：在真实语料上实现该构造，逐条检验。脚本见 `exploration/test_functional_representation.py`
与 `exploration/test_functional_sharper.py`，数字见 `records_centroid/functional_test*.json`。

---

## 结论摘要

| 主张 | 判定 | 实测 |
|---|---|---|
| 单射性 | ✅ **成立** | 特征核下 `Φ` 单射，数学无误 |
| `argmax` 自动还原 | ⚠️ **仅当 γ(t) ∈ Ω 时** | 帧外点的还原**不优于猜常数**（rel err ≈ 1.0） |
| 顺序变为信号 | ⚠️ **部分是** | 顺序确有可观痕迹，但**只区分"原序 vs 他序"** |
| 泛参照系是"泛"的 | ❌ **不成立** | 仅改 σ（×1.6），`Φ` 变化 **136–325%** |
| 路径签名可作更强还原 | ❌ **低阶签名对排列不变** | 见 §六 |

**总评**：作为**数学基底**，核嵌入是正确且更丰富的选择——它确实保留了标量丢失的信息。
但作为**测量协议**，它引入了一个未受控的自由参数（σ 与嵌入模型），
**其影响大于 C_T 的顺序敏感性**。提案把这个参数写成了一个符号，没有把它当作问题。

---

## 一、单射性：成立

定理 1 的证明正确。若 `K` 是特征性核（高斯核是），则

```
Φ(γ₁) = Φ(γ₂)  ⟹  K(·, γ₁(t)) = K(·, γ₂(t))  ∀t
                ⟹  δ_{γ₁(t)} = δ_{γ₂(t)}        （特征性）
                ⟹  γ₁(t) = γ₂(t)
```

**成立。** 但要注意一句**方法论的限定**：

> **单射性本身不足以说明这个表示比别的好。**
> 把全文连同每个字的编码存下来也是单射的。单射只保证"不丢"，
> **不保证"留下的是认知而不是噪声"**。

`Φ` 保留了**嵌入向量序列**的全部信息。它是否保留了**认知**，
取决于嵌入空间是否承载认知——这是另一个问题，不因单射而解决。

## 二、自动还原：数学成立，实践受限

定理 2 对**连续**的 `x ∈ Ω` 成立（高斯核单调，唯一最大值在 `x = γ(t)`）。
但实现必须把 `Ω` 离散化为有限 codebook，此时

```
argmax_{x ∈ codebook} Φ(γ)(x,t)  ∈  codebook
```

**它只能返回 codebook 里的点。**

### 实测

第一轮我在"帧 = 语料自身"下测，**还原误差为 0**——但那是**构造上必然**的，
没有检验任何东西。改为**帧外点**（codebook 不含被测语料）：

| 语料 | 还原误差 | 相对基线 |
|---|---|---|
| poem | 0.8783 | **1.0563** |
| machine_poem | 0.9325 | **1.0800** |
| hc3_human_medicine | 0.8877 | **0.9781** |
| hc3_ai_medicine | 1.0355 | **1.0913** |

**相对基线 ≈ 1.0**，其中基线是"直接猜帧的均值"的误差。

> **即：对帧外的轨迹，`argmax` 还原与猜一个常数一样差。**

而 codebook 尺寸的扫描（第一轮）显示误差随尺寸下降，
**但那只是因为随机 codebook 越来越可能撞上语料点**——不是还原变好。

**含义**：还原定理在实践中要求 **`Ω` 包含被测轨迹**。
对链上存证场景，这意味着**验证方必须持有 codebook**，
且**任何不在 codebook 中的作品无法被还原**。
`Ω` 因此不能是"先于任何轨迹"的固定集合，而**必须随语料增长**。

## 三、顺序：确有信号，但只区分"原序 vs 他序"

第一轮我用**随机打乱**测"顺序依赖部分"，得到 `‖Φ_ord‖/‖Φ_inv‖ = 2.18–5.06`。
**这个数被高估了**——随机打乱是极端的顺序改变，而其偏差范数在很大程度上
只是"单个点在 `E_π[Φ]` 这个质心远处的几何必然"，
在 593 维特征空间里尤其如此。

第二轮改用**都是"有意义的"顺序**对比：

| 语料 | 按长度重排 | 按哈希重排 | 随机打乱 |
|---|---|---|---|
| poem | 0.0523 | 0.1392 | 0.1413 |
| machine_poem | 0.0975 | 0.0987 | 0.1003 |
| lyrics | 0.2091 | 0.2867 | 0.2956 |
| techdoc | 0.2750 | 0.3015 | 0.3103 |
| hc3_human_medicine | 0.2302 | 0.2231 | 0.1957 |
| hc3_ai_medicine | 0.1891 | 0.1857 | 0.1700 |
| hc3_human_openqa | 0.4506 | 0.4605 | 0.4489 |

**关键观察：按哈希重排 ≈ 随机打乱**（0.1392 vs 0.1413、0.0987 vs 0.1003、
0.2867 vs 0.2956……几乎逐项相等）。

> **`Φ` 能区分"原序"与"任意其他序"，但分不清"哪一种其他序"。**

也就是说，顺序痕迹的量级是可靠的，**但它的方向不携带可辨识的结构**。
这与标量 `C_T` 的行为同源——两者都主要捕捉**相邻结构**，而非序列本身。
（差异在于 `Φ` 把这一信息保留得完整得多，而非压缩成一个数。）

## 四、泛参照系并不"泛"：σ 是未受控参数

提案把 `Ω` 写成 `(Ω, d, ν)`，其中 `σ` 出现在核里却未被当作参数讨论。
实测**固定帧、只改 σ**：

| 语料 | σ×0.6 | σ×0.8 | σ×1.25 | **σ×1.6** |
|---|---|---|---|---|
| poem | 0.9672 | 0.6690 | 1.0526 | **2.3956** |
| machine_poem | 0.9733 | 0.6883 | 1.1280 | **2.6058** |
| lyrics | 0.8316 | 0.5037 | 0.6430 | **1.3565** |
| techdoc | 0.9044 | 0.5824 | 0.8134 | **1.7724** |
| hc3_human_medicine | 0.9773 | 0.7077 | 1.2241 | **2.8897** |
| hc3_ai_medicine | 0.9840 | 0.7333 | 1.3456 | **3.2476** |
| hc3_human_openqa | 0.9218 | 0.6517 | 1.0667 | **2.4634** |

（数值为 `‖Φ_σ' − Φ_σ‖ / ‖Φ_σ‖`。σ×1.6 时 `Φ` 变化量是**它自身范数的 1.4–3.2 倍**。）

> **仅把 σ 从 0.55 改到 0.87，同一个轨迹的函数表示就几乎完全变成另一个。**

**这把问题从"顺序敏感 20–51%"换成了"σ 敏感 136–325%"。**
而 `σ` 的选择没有原则——我用的"中位距离的一半"只是一个常用启发式。

**提案声称 `Ω` "不因素材而改变"，但 `σ` 必须由素材标定**（中位距离来自语料），
所以 `Ω` 实际上**依赖素材**。这是提案中一处内部不一致。

## 五、对哲学回扣的一点保留

§八 主张"函数表示 → 不可压缩 → 意义本能保留"。

**两处需要区分**：

1. **数学表示 vs 存储**。`Φ` 是函数，但任何函数都能被哈希、存证、压缩存储——
   提案自己的 §九 就写了"哈希函数（Merkle over samples）"。
   "不可压缩"在这里是**侧重点的选择**（不取标量摘要），不是数学性质。
2. **`Φ` 的信息量由 σ 与核决定**，不由"函数形式"决定。
   σ 小到极限时 `Φ` 退化为近似独热编码，σ 大到极限时 `Φ` 退化为常数。
   **"保留了多少"是 σ 的函数，不是"是不是函数"的函数。**

**因此**："`C_T` 是对象化、`Φ` 不是"这一论断**过强**。
更准确的说法是：**`C_T` 是压缩，`Φ` 是较少压缩；
但压缩程度由 σ 控制，而 σ 未被理论决定。**
存在论要求需要 `σ` 的确定方式来支撑，否则它只是又一个自由参数。

（这一条是**方法论保留**，不是否定。函数化方向本身是对的。）

## 六、路径签名：一处数学错误

§七 写了：

```
S(γ) = (1, ∫dγ, ∫∫dγ⊗dγ, ...)
```

**但低阶签名对重参数化与排列是不变的**：

- 一阶项 `∫dγ = γ(T) − γ(0)`，**只依赖端点**，与中间顺序无关
- 二阶项 `∫∫_{s<t} dγ_s ⊗ dγ_t = ½[(γ(T)−γ(0))^{⊗2} − ∫[γ,γ]`，
  其**对称部分也只依赖端点**；顺序信息只存在于**反对称（Lévy 面积）部分**
- 因此**直到二阶都无法区分某些不同顺序的路径**

**签名的单射性依赖完整（无穷）级数**，且是对**树状等价**（tree-like equivalence）
而言的单射，不是对任意重排。**低阶截断会丢失顺序信息。**

**含义**：签名**不是**核嵌入的"更强版本"，而是**另一种取舍**：
签名无需 codebook、无需 σ，但需要无穷维且对低阶截断敏感；
核嵌入有限维、有还原算法，但需要 codebook 与 σ。
**提案把两者写成同一层次的递进，是不准确的。**

## 七、这次重构**确实解决**的问题

前面几轮的两个结论在这套框架下得到澄清：

### 顺序敏感性被重新定位

`C_T` 的顺序敏感（20–51%）之所以是"缺陷"，是因为标量**无法表达**它为何变化。
在 `Φ` 层面，顺序变化对应一个可测量的函数差异（上述 0.05–0.46），
**"顺序"从不可解释的抖动变成了可报告的量**。这是真实进步。

### 篇内一致性有了正确形态

提案没有直接讨论，但框架**自然支持**：
把**单篇作品**按段落切分为快照，`Φ(γ)` 的横轴就是段序——
**有内在意义**，不需要跨作品可比性。

这是第六轮诊断为"顺序任意"的那个问题的**正确出口**，
也是我建议下一步做的验证（见 §九）。

## 八、若要做成测量协议，必须先解决的三件事

| 问题 | 现状 | 需要 |
|---|---|---|
| **σ 的确定** | 由语料中位距离启发式给出，实测影响 136–325% | 原则性标定，或**对 σ 积分**（尺度不变化） |
| **codebook 的确定** | 帧外点无法还原，误差 ≈ 猜常数 | `Ω` 的定义与增长规则；或放弃 argmax 还原主张 |
| **嵌入模型** | 单一模型，实测换模型 C_T 差 31% | 多模型集成，或声明嵌入为协议固定部分 |

**第三项尤其重要**：`Φ` 的定义把嵌入模型 `R^d` 藏在 `Ω` 里，
但 `Ω` 是 `R^d` 的说法**没有指定是哪一个 `R^d`**。
换嵌入模型 = 换 `Ω` = 换整个测量。

## 九、建议的下一步：篇内轨迹

**最小可验证的一步**，且不依赖上述三个未决问题：

```
取 N 篇作品，各按段落切分为快照
对每篇计算 Φ(γ)（帧用全库段落嵌入）
检验：
  (a) 同一篇的段序是否有稳定形状（单调/峰/谷）？
  (b) 形状是否按体裁聚类？
  (c) 篇内 Φ 的差异是否大于篇间？
```

**为什么这一步值得先做**：

- **轴有内在意义**（段序不是任意排列）→ 绕开 §三 的顺序歧义
- **每篇独立**（不跨作品比较）→ 绕开长度、语域、模型三项混淆
- **成本低**：不需要新语料，现有的诗歌、歌词、技术文档都可按段切分

**若 (a)(b)(c) 中任何一项为否，则"每作品一条轨迹"这一方向本身需要重新考虑**——
而这正是提案的核心承诺。
