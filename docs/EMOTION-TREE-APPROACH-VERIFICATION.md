# 情绪树方案的借鉴价值：数学检验与判定

**日期**：2026-10-05
**被检验的方案**：借鉴情绪树论文的"匹配矩阵 + 非对称条件概率建树"，
用有向无环图（DAG）取代线性路径，以消解顺序敏感。
**方法**：先做纯数学检验（不依赖模型），再尝试在真实模型上实测
**脚本**：`exploration/emotion_tree_probe.py`
**状态**：⚠️ **建树规则被证伪；顺序不变性成立；实测受模型下载阻断**

---

## 摘要

| 主张 | 判定 | 依据 |
|---|---|---|
| 匹配矩阵 `C = YᵀY` 顺序无关 | ✅ **成立** | 构造上即集合级统计量 |
| 层级图天然顺序无关 | ✅ **成立** | 由此推出 |
| 无边界的核 → 无 σ 参数 | ✅ **成立** | 该方法不用核 |
| **非对称条件概率能定向层级** | ❌ **证伪** | **该规则只依赖边缘和** |
| 阈值/词表大小不主导结构 | ❌ **证伪** | `V > 1/t` 时边数归零 |

**净结论**：**顺序问题的解法是对的，建树规则是错的。**
方案的价值在于 `C = YᵀY` 这一步（确实顺序无关），
而不在于用它建出的"层级"——**那个层级是边缘不平衡的产物，不是层级结构**。

---

## 一、匹配矩阵这一步：成立

`Y`（N 素材 × V 情绪词）的第 i 行是第 i 个素材在探测短语后对情绪词的 next-token 概率分布。

```
C = Yᵀ Y
```

**无论素材以什么顺序排列，`Y` 的行只是重排，`YᵀY` 逐位不变。**

这一点是**构造上的必然**，不需要实测（我仍在脚本里写了断言以防实现出错）。
它与本项目测出的 `C_T` 顺序敏感（20–51%，见 `MEASUREMENT-VALIDITY.md` §三）
**完全相反**——**这是该方案相对 `Σμδ` 的真实优势。**

**并且它不需要核，因此也没有 σ。** 这比我前面检验的 `(Φ, Ψ)` 核嵌入方案**更彻底**：
核嵌入方案消解了顺序但保留了 σ；本方案两者都去掉了。

## 二、建树规则：证伪

### 规则原文

```
a 是 b 的父节点  ⟺  C_ab / Σ_i C_ai > t   且   C_ab / Σ_i C_ib < C_ab / Σ_i C_ai
```

### 化简

第二个条件中 `C_ab > 0`，**两边同除 `C_ab`**：

```
1/Σ_i C_ib  <  1/Σ_i C_ai     ⟺     Σ_i C_ai  <  Σ_i C_ib
```

**即：行和 < 列和。**

> **该条件完全不涉及联合项 `C_ab`，只依赖 `C` 的边缘和。**

### 实测验证（三组随机矩阵）

| 试验 | 原规则边数 | 仅用边缘和 | 是否完全一致 |
|---|---|---|---|
| 1 | 158 | 158 | ✅ 一致 |
| 2 | 158 | 158 | ✅ 一致 |
| 3 | 154 | 154 | ✅ 一致 |

**逐条相同。** 化简成立，规则确实是边缘规则。

### 在"没有层级结构"的矩阵上会怎样

| 矩阵 | "层级"边数 | 说明 |
|---|---|---|
| 均匀随机 20×20 | **156** / 380（41%） | 找到大量"层级" |
| **秩1外积 `r·cᵀ`（零交互）** | **170** | **比随机更多** |
| 常数矩阵（完美平衡） | 0 | 唯一正确的情形 |
| 手工构造的 10×10 真层级 | 72 | 也能找到 |

**秩1矩阵没有任何交互结构**（`C_ab = r_a·c_b`，各点对独立），
**却产生了 170 条"层级"边**——比均匀随机还多。

> **结论：该规则检测的是边缘不平衡，不是层级关系。**

## 三、阈值与词表规模主导结构

在**均匀随机**矩阵上，`C_ab` 的量级是 `1/V`（因行和约 `V/2`）。
所以第一个条件 `C_ab/Σ_i C_ai > t` 近似为 `1/V > t`：

| V | 随机矩阵边数 | 占可能边 |
|---|---|---|
| 10 | 43 | 47.8% |
| 20 | 156 | 41.1% |
| 40 | 503 | 32.2% |
| 80 | 700 | 11.1% |
| **135** | **0** | **0.0%** |

**当 `V = 135` 且 `t = 0.02` 时，`1/V = 0.0074 < t`，随机矩阵一条边都通不过。**

原文提到用 **135 个情绪词**。若阈值确为 `0.02` 量级，
则**阈值本身（而非数据）决定了哪些边存在**——
参数选择了结果，不是数据选择了结构。

〔整理者按〕**这不必然意味着原论文的结果无效。** 可能：
- 原文用的阈值与 `t = 0.02` 不同
- 原文的 `C` 归一化方式与我此处不同
- 原文在真实模型输出上，情绪词概率远高于均匀随机（很可能如此），
  使 `C_ab/Σ_i C_ai` 显著大于 `1/V`

**但没有可访问的原文与代码，我无法判定是哪一种。**
我能确定的是：**按用户给出的规则原样实现，它不度量层级。**

## 五、判定：这个方案值得借鉴哪一部分

### 值得借鉴 ✅

1. **`C = YᵀY` 作为顺序无关的集合级表示** —— 思路正确，且**不需要核、不需要 σ**
2. **"用图/树取代线性路径"的方向** —— 与 〔19〕的结论一致，且本方案更简洁
3. **输出层探针（只用 logits）** —— 不需要隐藏状态，成本低

### 不应采用 ❌

1. **非对称条件概率的定向规则** —— 实测为边缘规则，任意矩阵都能产出"层级"
2. **在 `V = 135` 下直接套用 `t = 0.02`** —— 阈值会主导结果

### 与前面 `(Φ, Ψ)` 方案的比较

| | `C_T` 标量 | `(Φ, Ψ)` 核嵌入 | **本方案（C = YᵀY）** |
|---|---|---|---|
| 顺序敏感 | ❌ 20–51% | ✅ 消解（边用 kNN） | ✅ **消解（构造保证）** |
| σ 参数 | 无（但有窗口） | ❌ 敏感 70–133% | ✅ **无核，无 σ** |
| 依赖 | 嵌入模型 | 嵌入模型 + σ + 核 | **模型 + 情绪词表 + 阈值** |
| 可还原 | ❌ | ⚠️ 近似（帧外 0.5–0.65） | ❓ 未验证 |
| 信息量 | 1 个标量 | 函数 | **V×V 矩阵 → 图** |

**本方案在"去参数"上优于核嵌入。** 但它把自由参数从 σ 换成了
**情绪词表（V 与具体词）+ 阈值 t + 探测短语**——
**自由度并未消失，只是换了位置。**
