## 一、Q1：Φ 是否决定 V —— 成立

### 检验方式

原提案的还原主张是 `γ(t) = argmax_x Φ(γ)(x,t)`。但早期测试表明，
**若把 Ω 离散为有限的 codebook，argmax 只能返回 codebook 成员**，
帧外点的还原"与猜常数一样差"（相对误差 0.98–1.09）——**那个测试测的是查找表，不是表示能力**。

正确的问题是：**Φ 作为函数，其峰是否就是节点？**
Φ 是核密度估计 `Φ(x) = Σ_v ℓ(v)K(x,v)`，用基函数固定在帧点上的 **RBF 网络**做最小二乘拟合，
再取拟合权重的峰作为恢复的节点位置。

### 结果

| 语料 | 帧内含语料 | 帧外（帧仅含 11/31） |
|---|---|---|
| poem | **31/31 精确** | 相对误差 0.5544 |
| lyrics | **31/31 精确** | 相对误差 0.5182 |
| techdoc | **31/31 精确** | 相对误差 0.6536 |

**帧内含语料时精确还原。** 帧外时相对基线（猜帧均值）为 0.52–0.65，
**优于早期查找表测试的 0.98–1.09**——说明 RBF 拟合确实提取了超出查找表的信息。

### 但这里有一个必须说清的限定

**"帧内含语料则精确还原"是构造上的必然，不是发现。**
RBF 基函数固定在帧点上，被测点本身在帧里，拟合自然把它选出来。

**真正的信息在帧外那一列**：0.52–0.65 说明还原**部分有效但不精确**。
因此还原主张的准确表述是：

> **Φ 决定 V 的前提是 Ω 包含 V。** 若 Ω 不含 V，还原是近似的（相对误差约 0.5–0.65）。

这对协议设计的含义：**Ω 不能是"先于任何轨迹"的固定集合**，
必须随语料增长，或接受近似还原。**这与原提案的"泛参照系"要求存在张力。**

## 二、Q2：图表示是否消解顺序敏感 —— 完全成立

这是换用图表示的**主要动机**，也是本次验证中最干净的结果。

### 两种边的构造

| 构造 | 定义 | 是否依赖读取顺序 |
|---|---|---|
| **路径图** | 相邻篇目连边 `(i, i+1)` | ✅ 依赖（任意） |
| **kNN 图** | 按成对相似度的前 k 个邻居连边 | ❌ **不依赖** |

### 置换检验结果（k=3）

| 不变量 | 路径图（相对变化） | **kNN 图** |
|---|---|---|
| weight_sum | 0.4402 – 0.5367 | **0.0000** |
| weight_mean | 0.4402 – 0.5367 | **0.0000** |
| degree_std | 0.3167 – 0.5427 | **0.0000** |
| spectral_gap | 0.9329 – **2.4012** | **0.0000** |
| **边集本身** | 置换后**不同** | **完全相同** |

**kNN 图在置换下逐位不变；路径图的不变量变化 32%–240%。**

这与本项目此前对 `C_T` 的实测直接对应（`MEASUREMENT-VALIDITY.md` §三：
按文件顺序的值落在全部 200 次打乱的 0.0 百分位，差异 20%–51%）。
**`C_T` 的顺序敏感来自"边 = 相邻"这一任意选择；换成"边 = 相似"，问题消失。**

### 一处诚实说明

kNN 图的不变量在置换下**恒等于**原值，这一点有代数上的必然性：
`w(u,v) = K(u,v)` 只依赖成对距离，而边集由距离排序决定，两者都与标号无关。

**所以这不是"意外发现"，而是"设计目标的达成"**——但它仍然是有意义的验证：
它证明**顺序敏感确实源于边的构造方式**，而不是源于度量本身。
把这条修好，顺序问题就真正解决了。

## 三、Q3：图表示是否消解 σ 敏感 —— 不成立

### 实测（σ 取中位成对距离的一半）

| 语料 | σ×0.6 | σ×0.8 | σ×1.25 | **σ×1.6** |
|---|---|---|---|---|
| poem | 0.5049 | 0.2560 | 0.3152 | 0.7006 |
| lyrics | 0.5653 | 0.2947 | 0.3506 | 0.7727 |
| techdoc | 0.5952 | 0.3669 | 0.5185 | **1.1593** |
| machine_poem | 0.6139 | 0.3993 | 0.5852 | **1.3132** |
| hc3_human_medicine | 0.6156 | 0.4031 | 0.5929 | **1.3258** |

（数值为 `‖Φ_σ' − Φ_σ‖ / ‖Φ_σ‖`）

**σ×1.6 时 Φ 的变化量超过它自身的范数**（techdoc 以上三例）。
图的不变量同样敏感（weight_sum 变化 0.43–1.45）。

**与标量 `C_T` 的顺序敏感（20%–51%）相比，σ 敏感（70%–133%）更大。**

### 为什么 σ 敏感是真实的（一处我先前的理论错误）

我起初推断：对 RBF 核，`K(x,v; σ) = exp(−d²/2σ²)`，
把 σ 换成 `kσ` 应当使 `K` 乘一个**常数**，于是归一化差为零。

**这个推断是错的。** 实测嵌入与几何：

```
嵌入范数      : min 1.0000  max 1.0000        ← L2 归一化，全在单位球面
逐维均值的范数 : 占用典型范数的 91.6%            ← 巨大共享分量
median 成对距离: 0.5616   (最大 √2 ≈ 1.4142)   ← 挤在小圆帽里
```

对**单位向量**，`d² = 2(1 − cosθ)`，所以

```
K = exp( −(1 − cosθ) / σ² )
K'/K = exp( (1 − cosθ)·(1/σ² − 1/σ'²) )        ← 逐项不同，不是常数
```

**除非所有成对距离都相等**，否则换 σ 会对不同的点对重新加权。
**σ 敏感是嵌入几何的必然结果，不是实现缺陷。**

## 四、中心化无效 —— 另一处被推翻的假设

我推断：既然存在 91.6% 的共享分量，**中心化**（减去均值）应当扩大距离的分散度，
从而降低 σ 敏感。

### 实测

| 语料 | 原始 Φ 敏感度均值 | 中心化后 | 距离 CV（原始→中心化） |
|---|---|---|---|
| poem | 0.4442 | **0.4442** | 0.358 → 0.354 |
| lyrics | 0.4958 | **0.4958** | 0.326 → 0.326 |
| techdoc | 0.6600 | **0.6600** | 0.152 → 0.152 |
| machine_poem | 0.7279 | **0.7279** | 0.108 → 0.108 |
| hc3_human_medicine | 0.7344 | **0.7344** | 0.087 → 0.087 |

**逐项到小数点后四位完全相同。**

**原因**：RBF 核**只依赖成对距离**，而中心化**几乎不改变距离矩阵**——
移除共享分量相当于对原点做平移，单位球面上的距离基本不变。

〔整理者按〕这是一处**假设被数据推翻**的记录。
我原本预期中心化会改善，实测完全没有。保留在此以免后人重试。

## 五、新发现：σ 敏感度可由距离分布预测

虽然 σ 敏感不可消除，但**它的大小是可预测的**：

| 语料 | 成对距离 CV | σ×1.6 敏感度 |
|---|---|---|
| poem | 0.358 | 0.7006 |
| lyrics | 0.326 | 0.7727 |
| techdoc | 0.152 | 1.1593 |
| machine_poem | 0.108 | 1.3132 |
| hc3_human_medicine | 0.087 | 1.3258 |

```
CV 与 σ×1.6 敏感度:  r = −0.9981     (n = 5)
CV 与 σ×0.6 敏感度:  r = −0.9227
```

**语料越同质（成对距离越集中），σ 敏感度越大。**

**机理**：距离越集中，`(1 − cosθ)` 的带宽越窄，
换 σ 相当于对一簇高度相近的权重做统一的重新缩放——
**敏感性集中在"缩放倍率"上，而非"哪些点对被重加权"**。

**实用判据**：

> 计算成对距离的 CV。**CV < 0.15 时，σ 选择会主导测量结果**，
> 此时 σ 必须固定并声明，且**不应跨语料比较 Φ 的数值**。

〔限制〕n = 5，相关系数虽接近 −1，但**样本太少，不能作为定律**。
需要更多语料与更多 σ 取值才能确立。

## 六、协议层面的结论

综合 Steps 1–2，`(Φ, Ψ)` 的正确表述是：

### 可以主张的

1. **Φ 决定 V**（Ω 含 V 时精确；否则近似，相对误差 0.5–0.65）
2. **图表示消解顺序敏感**：边由相似度而非相邻决定后，置换下**完全不变**
3. **σ 敏感可预测**：由成对距离 CV 给出（CV 小则敏感大）

### 不能主张的

1. ❌ Φ **消除了**自由参数——**σ 仍在，且影响大于 C_T 的顺序敏感**
2. ❌ 中心化或任何距离保持变换能改善 σ 敏感
3. ❌ 跨语料比较 Φ 的数值（除非 σ 固定且距离 CV 相近）

### 因此 σ 的定位

**σ 应当被当作协议的一部分，与嵌入模型的地位相同。**

这是可以接受的立场，理由：
- `BAAI/bge-large-zh-v1.5` 已经是协议的一部分（换模型 C_T 差 31%，见 `MEASUREMENT-VALIDITY.md` §六）
- σ 由**中位成对距离的一半**确定，是**确定性**规则，可复现
- 只要**声明并固定**，测量是可重复的

**但这个立场必须写进论文**：`Φ` 是 `(嵌入模型, σ, 核, 图构造)` 的联合产物，
**不是一个只依赖文本的函数**。原提案把 σ 写成一个符号，未把它当作待声明的协议参数。
