# 意识流沉积测度：情绪树动态区域定位

**日期**：2026-10-05
**模块**：`pacsp_emotion.py`
**验证**：`exploration/emotion_region_test.py` → `results/emotion_region.json`
**上游方向**：`PACSP-collection/03-PACSP-情绪树` 对话的最终诉求（消息 56）——
> 「根据文本内容，找到在情绪树结构中激活的动态区域。」

---

## 摘要（一句话）

> 不再把文档压成一个"体量"标量，而是把文档的分段序列（意识流）投影到一棵**固定的情绪树骨架**上，定位它激活的**动态区域**——哪些节点被激活、激活如何沿流迁移、激活质量最终**沉积**在哪棵子树上。

这直接对应目标的"意识流沉积测度"：

| 概念 | 本模块中的对应 |
|---|---|
| 意识流 | 文档的分段序列 `T_1 … T_K`（生成顺序） |
| 沉积 | 分段激活在情绪树上的累积质量 `S(w) = Σ_k a_k(w)` |
| 测度 | 定位结果：主导簇 + 逐段轨迹 + 沉积分布 + 浓度 |

---

## 一、定位：这是第三个对象，不是前两个的修补

| 量 | 对象 | 性质 |
|---|---|---|
| `D`（成对距离均值） | 文本集合的语义散布 | 顺序无关、语料级、**测文本自身** |
| `S`（`S_flow`/`S_recur`/`S_sed`） | 单文档内部的语义复现 | 顺序有关、文档级、**测文本自身** |
| **情绪树动态区域** | 文本 ↔ 情绪树结构的**关系** | 顺序有关（轨迹）、**测文本激活了树的哪块区域** |

前两者测"文本是**什么**"，本模块测"文本在情绪结构上**落在哪、怎么动、往哪沉积**"。
这是消息 57 明确区分过的对象——前者的失败（词表/短语主导）不蕴含后者不可行。

---

## 二、静态骨架：一棵声明式的情绪树

早前的情绪树尝试是从 `C = YᵀY` **推导**层级，被证明被边缘分布主导。
本模块反其道：树是**预先固定、逐字声明**的参照结构（与参照系 `Ω` 同地位），
投影只是"把文本放上去定位"，不推导任何结构。

骨架 = 13 个基本情绪簇（一级节点）+ 各自叶子（二级节点），共 128 词，
与 `emotion_tree_probe.py` 的词表完全一致，只是被组织成树：

| 价性 | 簇（一级） | 叶子数 |
|---|---|---|
| 正性 | 喜悦 / 乐观 / 平静 / 爱 / 感激 / 激励 | 6 × 9 |
| 负性 | 悲伤 / 孤独 / 愤怒 / 恐惧 / 羞愧 / 厌倦 | 5 × 9 + 7 |
| 中性 | 惊讶 | 9 |

**声明的选择只有三个**：树骨架（上面这张表）、嵌入空间（`bge-large-zh-v1.5`）、
温度 `τ`（软最大化温度，见下）。三者都显式、可审计、可改。

---

## 三、投影：嵌入相似度（零探针、零词表子集）

消息 51/55 的教训是：用探针短语 + 情绪词子集去"访问"分布，会被这两者主导
（探针措辞跨 826 倍、词表换子集方向反转）。本模块**不用 next-token 概率**，
改用嵌入相似度：

\[
a_k(w) = \text{softmax}\!\Big(\frac{\cos(v_k,\,e_w)}{\tau}\Big)
\]

其中 `v_k` 是第 k 段的嵌入，`e_w` 是情绪词 w 的嵌入，`τ` 是温度。
这**零探针、零额外语言模型**，完全复用项目已声明的参照系 `Ω`。

---

## 四、动态区域定位

对一篇文档：

1. **分段**：复用 `pacsp_stream.segment_document`（段 → 行 回退）。
2. **激活投影**：每段得到情绪词上的分布 `a_k`。
3. **沉积**：`S(w) = Σ_k a_k(w)`（归一化）——意识流在树上累积的情绪质量。
4. **主导区域**：沉积质量最大的簇（子树）。
5. **轨迹**：逐段的主导簇序列 `A_1 → … → A_K`——"动态"部分。
6. **浓度**：主导簇占全部沉积质量的份额（单一标量摘要，不是判据本身）。

输出是**一个区域**（节点集 + 轨迹 + 沉积分布），不是一个数。

## 五、实测结果（`results/emotion_region.json`）

### 5.1 可解释性 ✅

手写片段 → 激活的前 5 词，全部落在语义正确的簇：

| 片段 | 激活簇 |
|---|---|
| 「我很难过，失去了一切…」 | 失落 / 难过 / 悲伤 / 痛苦 / 沮丧 |
| 「今天特别开心，梦想实现…」 | 喜悦 / 欣慰 / 高兴 / 自豪… |
| 「对不公感到愤怒和怨恨」 | 怨恨 / 生气 / 愤怒… |
| 「深夜独自一人…孤独与寂寞」 | 孤独 / 寂寞 / 失落 / 难过… |
| 「实验结果令人震惊…」 | 惊讶簇（震惊 / 意外 / 诧异…） |

**投影忠实于文本内容**，且没有经过任何情绪标签监督。

### 5.2 温度稳健性 ✅

主导簇在 `τ ∈ {0.05, 0.1, 0.2, 0.5}` 下与 `τ=0.1` 的一致率 ≥ 0.74（多数 ≥ 0.90）；
仅在极端 `τ=0.02` 下 `machine_lyrics` 降到 0.42。**温度不是主导参数**
（`τ=0.1` 为默认，已验证）。

### 5.3 人机对比：沉积浓度方向一致，3/3 区间排除 1

| 配对 | 人类沉积浓度 | 机器沉积浓度 | 比值 | 95% 区间 |
|---|---|---|---|---|
| poem / machine_poem | 0.1204 | 0.1443 | 0.8345 | [0.7780, 0.8999] |
| lyrics / machine_lyrics | 0.1031 | 0.1438 | 0.7167 | [0.6855, 0.7487] |
| techdoc / machine_techdoc2 | 0.1041 | 0.1143 | 0.9102 | [0.8771, 0.9482] |

**三个配对方向一致且区间全部排除 1**（`results/emotion_region_intervals.json`，
自助法 n=2000）：机器（智能体）输出把情绪激活**更集中**地沉积在单一簇上，
人类输出**更分散**（单篇内情绪多样性更高）。

主导簇本身（孤独/悲伤/感激/惊讶）在两臂间**大量重叠**，说明这主要不是
"人类与机器表达不同情绪"，而是"**情绪的散布结构**不同"。效应量中等
（lyrics 比值 0.72 最强，techdoc 0.91 最弱）。

### 5.4 跨编码器稳健性（仿 §4.9）

| 编码器 | 家族 | poem | lyrics | techdoc |
|---|---|---|---|---|
| bge-large-zh-v1.5 | bge | 0.8345 | 0.7167 | 0.9102 |
| bge-small-zh-v1.5 | bge | 0.8022 | 0.8158 | 0.9255 |
| text2vec-base-chinese | 其他 | 0.7886 | 0.6521 | 0.9518 |

**3 编码器 × 3 配对 = 9/9 区间排除 1**，方向一致（机器更集中）。
`D` 的判别力在 §4.9 中因换家族而收缩（text2vec 仅 3/5），
**本测度跨家族依然全部成立**——方向稳健性显著强于 `D`。

### 5.5 跨骨架稳健性（`emotion_skeleton_robustness.py`）

树骨架是声明而非实证，须验证方向是否由"13 簇"这一选择驱动。把同一激活
重聚合到更粗的骨架上（`results/emotion_skeleton_robustness.json`）：

| 骨架 | poem | lyrics | techdoc | 判定 |
|---|---|---|---|---|
| 13 簇 | 0.8345 | 0.7167 | 0.9102 | 3/3 排除 1 |
| 3 价性（正/负/中） | 0.9282 | 0.9214 | 0.9385 | 3/3 排除 1 |
| 2 价性（正/非正） | 1.0000 | 1.0000 | 1.0000 | 饱和，无信号 |

**方向在"13 簇 → 3 价性"的适度粗化下保持**（效应量收缩：比值从 0.72–0.91 抬到
0.92–0.94）；**粗化到 2 类则饱和**——温度 0.1 的激活足够尖锐，使每篇几乎全落在
单一价性，两侧浓度都趋近 1.0，度量失去分辨力。即：骨架粒度是必须声明的选择，
效果在 13 簇粒度最强。

## 六、局限与未完成

1. **仅三个配对**：情绪内容最清楚的只有 poem/lyrics/techdoc 三对；HC3（问答）与
   高考作文未纳入本轮。
2. **温度与阈值之别**：本模块只有一个温度参数 `τ`；消息 57 提出的"激活阈值 τ"
   （决定"激活/未激活"的二元切分）尚未实现——当前输出是连续沉积分布，不靠阈值。
3. **树骨架是声明而非实证**：13 簇的划分是组织选择，非从模型读出；§5.5 已测
   方向在适度粗化（3 价性）下保持，但极端粗化（2 价性）饱和——骨架粒度须声明。
4. **温度与骨架的耦合**：浓度在温度更尖锐时更趋饱和（§5.5 的 2 价性饱和即由此）。
   默认 τ=0.1 已作敏感性扫描（§5.2），但未系统扫 τ × 骨架 的组合面。

```python
from pacsp_emotion import tree_index, word_embeddings, document_region
from sentence_transformers import SentenceTransformer
m = SentenceTransformer("BAAI/bge-large-zh-v1.5")
embed = lambda t: m.encode(list(t), batch_size=8, normalize_embeddings=False)
words, cluster, valence = tree_index()
W = word_embeddings(embed, words)
r = document_region(text, embed, W, temperature=0.1)
# r: dominant_cluster / trajectory / cluster_sedimentation / sediment_concentration
```
