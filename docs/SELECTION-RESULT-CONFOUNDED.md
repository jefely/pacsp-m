# 纯筛选对照实验：结果与一个致命的混淆

**日期**：2026-10-05
**设计**：31 道高考作文题，每题两个模型的稿件，读者二选一
**状态**：⚠️ **实验未能测到筛选效应——混淆无法分离**

---

## 一、设计意图

论文 §10.5 的判定轴是"**人是否对 AI 输出施加了筛选**"。原三臂设计需要真人独写，
而整理过程中确认：**公开语料没有中间臂，精选范文又是筛选产物**。

于是改用**纯筛选对照**：

| 臂 | 文本来源 | 人类筛选 |
|---|---|---|
| `gaokao_chosen` | 模型生成（读者选中的） | ✅ 有 |
| `gaokao_unchosen` | 模型生成（读者落选的） | ❌ 无 |

**两臂同为机器所写**，故理论上差异只能来自筛选。

三项控制：

| 控制 | 做法 |
|---|---|
| 题面 | 两稿同题 |
| 长度 | 都裁到句边界、同一上限（均值 764 vs 766 字符） |
| 位置 | 每题随机（31 份中 r1 在前 12 份） |

## 二、结果

读者完成 13 题（题 1–13）后，实测：

```
gaokao_chosen     C_T = 3.5483 Se
gaokao_unchosen   C_T = 3.8648 Se
比值              0.918
```

看起来是"**人倾向选择 C_T 更低的稿**"——即人类偏好更平顺的文本。

## 三、但这个读数**不可用**：混淆无法分离

同一批决策的另一个数字：

```
读者选中的稿件来自哪个模型：
  deepseek-r1:14b   9 次   (69%)
  qwen2.5:7b        4 次
```

而**两个模型的全臂 C_T**（各 31 篇，同一套题）：

```
qwen2.5:7b         C_T = 9.5902
deepseek-r1:14b    C_T = 6.6421        比值 0.693   ← r1 本身低 31%
```

**13 次决策中，没有一次是同模型内部的选择**——全部都是跨模型。

于是：

```
r1 稿 C_T 低 31%（0.693）
读者 69% 选 r1
  ↓
选中臂 C_T 自然更低（0.918）
```

**`0.918` 与 `0.693` 同向。** 因此 `0.918` 完全可能是"偏好 r1 这个模型"的投影，
**而不是**"偏好低 C_T"。

> **结论：本实验实际测的是 qwen 与 r1 的风格差异，不是人类筛选效应。**

## 四、这不是执行问题，是设计问题

三处对照设计是有效的：

| 控制 | 实测 | 判定 |
|---|---|---|
| 长度 | 选中 778 字符 / 落选 753 字符（0.968） | ✅ **平衡** |
| 位置 | r1 在"候选一"仅 12/31 | ✅ 随机化生效 |
| 题面 | 完全同题 | ✅ |

**长度与位置都被控制住了，混淆来自"两个模型的 C_T 差距太大"（31%），
压过了筛选效应。** 换言之：**设计里缺少一层隔离——稿件来源必须单一。**

## 五、附带发现（本身可用）

| 发现 | 数值 |
|---|---|
| **同一题、同一提示，仅换模型** | C_T 相差 **31%** |
| qwen2.5:7b 全臂 | 9.5902 Se |
| deepseek-r1:14b 全臂 | 6.6421 Se |

这与本项目此前多项发现一致：**C_T 对生成方式高度敏感**。
对论文的含义是——C_T 若要作为"认知沉积"的稳定指标，
**必须先量化它对模型、提示、采样参数的敏感性**，否则跨模型比较无意义。

## 六、若要修正，正确的设计是什么

**必须让两稿来自同一模型、同一提示，只在不同采样下生成**：

```
每题：qwen2.5:7b 生成 N 稿（不同种子）
      ↓
读者标出"达标的"与"不达标的"
      ↓
同模型内比较 → C_T 差异只能来自筛选
```

**多重草稿优于二选一**：二选一每题只给 1 bit 信息；5 稿达标判定约 2.3 bit。

〔整理者按〕当时向作者提出过这个修正（每题 3 或 5 稿），作者选择**暂不继续**
（记作方案 C），转而要求把 C_T 测量工具封装并提交。**本实验以现状归档，不再扩展。**

## 七、必须记住的一条限制

**本实验（即使修正）也无法回答 §8.5 的「人脑 vs LLM」判定。**

它测的是"人类的选择是否与 C_T 相关"；§8.5 声称的是
"这些指标能识别人与机器的差异"。**两者不是同一个命题。**
后者**必须**有未经筛选的真人独写语料——哪怕只有 10 篇、写得朴素。
